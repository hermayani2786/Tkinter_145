Kode ini buat bikin aplikasi desktop simpel pakai Python Tkinter untuk menebak jurusan kuliah berdasarkan 10 nilai pelajaran. Pertama, window utamanya dibuat ukuran 500x600 dengan latar warna abu-abu muda. Supaya kodenya gajadi panjang dan rapi, dipakai perulangan for buat langsung nampilin 10 kolom input nilai sekaligus. Pas tombol "Hasil Prediksi" diklik, fungsi prediksi_prodi() bakal ngerubah label di bawahnya buat nampilin tulisan "Prediksi Prodi: Teknologi Informasi". Terakhir, root.mainloop() dipasang supaya aplikasi tetap terbuka pas dijalankan.
